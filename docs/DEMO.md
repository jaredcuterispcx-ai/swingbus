# Manual demo script (two phones)

1. **Ground control** laptop: open `/dispatch` → Seed scenario.
2. **Driver phone A**: `/driver` → callsign `Green-1` (or accept existing) → allow GPS → Accept clearance.
3. **Driver phone B**: `/driver` → `Blue-2` → allow GPS.
4. **Passenger phone**: scan stand QR or open `/passenger/hq-lobby` → party 2 → destination.
5. Watch ground control: stand demand, seat tape (free/held/onboard), clearances.
6. Driver boards at stand → held becomes occupied; available rises only after alight.
